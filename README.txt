【BlockNoise Player】ブロックノイズが出ない軽量mp4プレイヤー(Rust + libmpv)

■ EXEの作り方(Rust環境は不要。GitHubで自動ビルド)
1. GitHubで新しいリポジトリを作成(Private可)
2. このフォルダの中身(Cargo.toml / src / .github / README.txt)をそのままアップロード
   ※ .github フォルダを忘れずに(隠しフォルダ扱いの場合あり)
3. リポジトリの「Actions」タブ → build が緑になるまで待つ(数分)
4. 完了した実行結果の「Artifacts」から blocknoise-player をダウンロード
5. 展開すると blocknoise-player.exe と libmpv-2.dll が入っています(同じフォルダに置く)
   インストール不要。mp4をEXEにドラッグ&ドロップで再生。

■ ビルドが赤くなったら
Actions の失敗ログ(赤いステップの出力)をコピーして教えてください。直します。

■ 操作(メイン操作は画面下のボタンバー。h キーでバーの表示/非表示)
ボタン  : -30秒 / -5秒 / 再生・一時停止 / +5秒 / +30秒 / 音量- / 音量+ /
          ミュート / ズーム / 表示サイズ / 全画面 / ノイズ除去
表示サイズ: ボタン(または w キー)を押すたびに切替
          全体表示(ウィンドウに収める・黒帯あり) → 埋める(はみ出し部分はカット)
          → 引き伸ばし(縦横比を無視してウィンドウ全体に) → 全体表示…
          ※切り替えるとズーム・移動は等倍にリセットされます
          (バー左上に 再生位置 / 長さ / 音量% を表示。音量は10%刻みで最大200%)
ズーム  : 「ズーム」ボタン(または z キー)でズームモードON
          → ONの間、動画をクリックするたびにクリック位置を中心に拡大(1.5倍ずつ、最大6倍)
          → 右クリックで縮小 / BS キーで等倍リセット
          → もう一度ボタンを押すとOFF(OFFの間はクリックしても何も起きません)
音量    : ↑↓ またはホイール(0〜200%)  m ミュート
再生    : Space 一時停止 / ←→ 5秒 / Shift+←→ 30秒 / f 全画面 / q 終了
d キー  : 元動画のブロック除去フィルタ ON/OFF(低ビットレート動画用)

■ ブロックノイズ対策
ソフトウェアデコード(hwdec=no)、H.264デブロッキングを常に有効、
画質を落とす高速化・フレーム省略を全て無効、deband有効。
