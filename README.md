# 軽量ファイラー (LightFiler)

Android 4.4 (API 19) 以降。AndroidX・外部ライブラリ不使用、リソースなし、Java のみ。

## ビルド
- Android Studio で開いて Build > Build APK、または `gradle assembleRelease`
  (JDK 17 + Android SDK 34 が必要)。
- 手元に環境がなければ GitHub にプッシュすれば Actions が APK を生成します
  (`.github/workflows/build.yml` は Web 画面の「Create new file」から作成してください)。
- release ビルドは R8 で縮小済み、デバッグ鍵で署名済み(そのままインストール可)。

## 画面構成
- 最上部: 表示切替(一覧 / サムネ) ・ 内部ストレージ ・ SDカード
- 容量バー: 現在のストレージの 使用 / 合計 / 空き。複数選択中は「選択 n 件 合計 xx」を追加表示
- パス: 各階層をタップするとそのフォルダへ移動
- 下部: ファイル選択中は全操作ボタン(コピー/切り取り/削除/名前変更/共有/全選択/詳細/選択解除)、
  コピー・切り取り後は「ここに貼り付け」バー

## 表示
- 一覧: 動画は小サムネ + `ファイル名` / `解像度 | 長さ | サイズ | 更新日`
  フォルダは `Nファイル / 合計容量 | 更新日`
- サムネ: 横3列(横向きは5列)。動画は `解像度 | 長さ` と `サイズ` のみ表示(ファイル名なし)。
  フォルダ・動画以外のファイルは識別のため名前を表示。
- 動画情報・サムネ・フォルダ集計は表示中の項目だけ裏で取得(スクロールが重くならない)。

## 機能
- 長押しで選択開始、タップで選択追加/解除
- 新規作成(フォルダ / 空ファイル)、貼り付け、検索(配下を再帰)、隠しファイル切替
- 並べ替え: 名前 / 更新日 / サイズ / 種類 / 解像度 / 動画の長さ × 昇順・降順
  (解像度・長さ順は、そのフォルダの動画情報を先にまとめて取得してから並べ替え)
- タップで外部アプリ(動画プレーヤー等)で開く

## SDカード
- Android 5.0+: メニュー「SDカード書込み許可」で最上位フォルダを一度選べば読み書き可。
- Android 4.4: OS 仕様でSD全体への書き込み不可 → メニュー「ストレージ切替(その他)」>
  「SDカード アプリ専用領域」で書込み可(読み取りはSD全体で可能)。
