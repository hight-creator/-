# 軽量ファイラー (LightFiler)

Android 4.4 (API 19) 以降。AndroidX・外部ライブラリ不使用、リソースなし、Java のみ。

## ビルド
- Android Studio で開いて Build > Build APK、または `gradle assembleRelease`
  (JDK 17 + Android SDK 34 が必要)。
- 手元に環境がなければ GitHub にプッシュすれば Actions が APK を生成します。
- release ビルドは R8 で縮小済み、デバッグ鍵で署名済み(そのままインストール可)。

## 機能
- 一覧: 動画は「再生時間 | 解像度 | サイズ | 更新日」、他は「サイズ | 更新日」。
  動画情報は表示中の行だけ裏で取得(スクロールが重くならない)。
- 長押しで複数選択 → コピー/切り取り/削除/名前変更/共有/全選択/詳細
- 貼り付け、新規フォルダ、検索(配下を再帰)、並べ替え(名前/日付/サイズ/種類)、隠しファイル切替
- ファイルをタップで外部アプリ(動画プレーヤー等)で開く
- SDカード: Android 5.0+ は「SDカード書込み許可」で一度だけ最上位フォルダを選べば読み書き可。
  Android 4.4 は OS 仕様でSD全体への書き込み不可 → 「ストレージ切替 > SDカード アプリ専用領域」で書込み可(読み取りはSD全体で可)。
